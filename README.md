# Smart Door Lock

An embedded electronic door-locking system using RFID/NFC authentication, with future support for networking and camera-based recognition.

## Project Status

🟡 Planning

## Objectives

- RFID/NFC-based access control
- Embedded lock control
- Authentication and access management
- Secure handling of failed authentication attempts
- Power-loss handling
- Access logging
- (Potentially) Wi-Fi connectivity
- (Potentially) Camera-based authentication

## Roadmap

1. Requirements & architecture
2. Hardware selection
3. RFID prototype
4. Lock control
5. Security & reliability
6. Access logging
7. Networking
8. Camera integration
9. AI-based authentication
